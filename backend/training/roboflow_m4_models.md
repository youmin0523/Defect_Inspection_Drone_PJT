# M4 — Roboflow Universe Candidate Models (Indoor Architectural Context Segmentation)

Target: interior context segmentation — classes **wall, ceiling, floor, window, door** (ADE20K-like indoor room semantic/instance segmentation).
Use case: run locally via the `inference` python package (`model_id = "<workspace-slug>/<project-slug>/<VERSION>"`) and ensemble with our own M4 model for a commercial drone building-inspection product.

Researched: 2026-05-30 via WebSearch.

> **Data-confidence note.** Roboflow Universe project pages are JS-rendered and Cloudflare-protected; WebFetch returned 403/401 and `curl` hit a JS challenge, so **per-page fields could not be read directly from the live pages** — every value below comes from search-engine snippets that quoted the page metadata. Classes, license, project-type, and model architecture are well-corroborated across multiple snippets; image counts and mAP are single-source and tagged "verify in UI". **Version numbers are mostly unconfirmed** — open each project's "Versions" tab in the Roboflow UI to read the exact trailing version for the `model_id`. Nothing is guessed; unconfirmed fields are labeled per the project's no-unverified-claims rule. Re-confirm license + version in the UI before any commercial deployment.

## Recommendation (3 lines)

1. **Best single commercially-licensed, confirmed-deployable model: `wallceilingfloor/wall-ceiling-floor-m6bao/1`** — the only candidate with a confirmed usable version (`/1`), confirmed instance-seg (YOLOv11-seg), CC BY 4.0, and a real metric (~88.7% mAP@50); it covers wall/ceiling/floor but NOT window/door, so for full 5-class coverage pair it with `bytetrooper/room-detection-tfaxd` (CC BY 4.0 instance-seg, adds window+door) in the ensemble.
2. **Best raw class coverage** is `panopticindoor/panoptic-indoor-segmentation` (all 5 classes, CC BY 4.0) but it appears to be a **dataset with no confirmed trained model version** and uses 93 COCO-panoptic labels requiring remap — do not rely on it until a deployable version is confirmed in the UI.
3. **Version numbers:** ONLY candidate 1 has a confirmed version (`/1`). Candidates 2–6 are **"version unconfirmed"** — fill the trailing `/<VERSION>` from each project's Versions tab before `inference` will load them. Licenses read CC BY 4.0 (commercial-OK) for candidates 1–4 and 6; candidate 5 license is unconfirmed. None read CC BY-NC in snippets, but **confirm license + version in the Roboflow UI before commercial deployment**, and drop any CC BY-NC.
